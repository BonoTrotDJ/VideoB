# Video BonoTrot v1.0.5

## Novità

- aggiornata l'estrazione degli stream dai player che usano `window._econfig`;
- decodifica locale del vero URL `.m3u8` direttamente sul dispositivo Android;
- riproduzione tramite proxy locale, senza dipendere dal proxy PHP del server;
- mantenimento automatico di referer e origin richiesti dallo stream;
- compatibilità con Flutter 3.44 e con il compilatore Kotlin aggiornato.

- versione applicazione: `1.0.5`;
