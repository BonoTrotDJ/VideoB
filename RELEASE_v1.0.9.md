# Video BonoTrot v1.0.9

## Novità

- badge `LIVE` aggiornato automaticamente ogni 30 secondi;
- aggiornamento automatico in background della lista importata ogni 5 minuti e alla riapertura dell'app, senza interrompere la visione;
- nuovo pulsante `Link salvati`: conserva i link dei canali visti negli ultimi 30 giorni, così restano raggiungibili anche quando non compaiono più negli eventi.

## Build

- versione applicazione: `1.0.9`;
- build Android: `10`;
- tag release consigliato: `v1.0.9`.
